# Бесплатный запуск: Render Free + внешняя PostgreSQL

С 30 октября 2026 основной `render.yaml` использует бесплатный web service без диска. Прежний платный вариант сохранён в `render-paid.yaml`. Условия площадок могут меняться: https://render.com/docs/free и https://neon.com/pricing.

На Render Free SQLite не подходит для сохранения аккаунтов: файловая система временная. Настройки `config.render_free_settings` требуют внешнюю PostgreSQL через `DATABASE_URL`; без адреса запуск останавливается, автоматического перехода на временную SQLite нет. Локальная версия по-прежнему использует свою SQLite.

## Создание базы

В Neon создайте проект `codestart` на тарифе Free, по возможности в регионе Frankfurt рядом с приложением. Откройте Connect и скопируйте PostgreSQL connection string. Строка начинается с `postgresql://`, включает пароль и параметры TLS; копируйте весь адрес, без команды `psql` и без внешних кавычек. Вставьте его только в секретную переменную `DATABASE_URL` на Render. Не присылайте его в чат и не коммитьте.

Бесплатная база самого Render истекает через 30 дней, поэтому для продолжительного использования выбран внешний провайдер. Бесплатные тарифы ограничены квотами; это не обещание неограниченного сервиса.

## Ручное заполнение New Web Service

| Поле | Значение |
| --- | --- |
| Name | `codestart` или `CadeStart` |
| Language | `Python 3` |
| Branch | `main` |
| Region | `Frankfurt` |
| Root Directory | оставить пустым, удалить `deploy/` |
| Build Command | `bash deploy/render-free-build.sh` |
| Start Command | `python -m deploy.render_start` |
| Compute | `Free — $0/month` |

Environment Variables:

| Имя | Значение |
| --- | --- |
| `PYTHON_VERSION` | `3.14.10` |
| `DJANGO_SETTINGS_MODULE` | `config.render_free_settings` |
| `DJANGO_DEBUG` | `false` |
| `DJANGO_SECRET_KEY` | содержимое локального `artifacts/render-secret.txt` |
| `DATABASE_URL` | полный адрес подключения из Neon |

В Advanced задайте Health Check Path: `/health/`. Диск и платную базу добавлять не нужно. После заполнения всех переменных можно запускать Deploy web service на выбранном Free.

## После запуска

Миграции выполняются перед стартом Gunicorn. На новой внешней базе появятся учебные материалы; локальные аккаунты и прогресс автоматически не переносятся. Проверьте регистрацию и сохранение после перезапуска сервиса. `/health/` проверяет доступ к базе, но не доставку почты или AI.

SQLite-команда `backup_database` в этом режиме не применяется; резервное хранение PostgreSQL нужно организовать средствами провайдера или `pg_dump` вне временной файловой системы Render. На сервере Free нет автоматической SQLite-копии перед миграцией. Возможности и сроки хранения копий зависят от плана базы.

Render Free засыпает после периода без запросов, поэтому первое открытие может быть медленным. AI требует отдельного ключа и оплачивается у провайдера независимо от бесплатного хостинга. Реальная доставка email также требует настроенного почтового сервиса.
